# KayKit 素材目錄與用法建議（2026-10-24 整個看過一遍）

> 作者 10/24：KayKit 有很多樹、桶、水、木箱、門、寶箱、錢幣、肉、人物、RPG 工具（含魚竿）都能用，先整個看過一遍。
> 下面是我下載後逐包列出模型清單、用圖鑑頁（`tools/gallery.html`）看過的結論。**全部是 CC0，免費、可商用、不用標示作者**（`License.txt` 逐包確認過；整包都放在 `assets/kaykit_*/`，不進 git，用到才複製進 `assets/models/`）。

## 0. 先講結論（跟你印象不一樣的地方）
1. **魚竿：RPG Tools Bits 裡沒有。** 我把 49 個工具全部看過：有鏟子、斧頭、十字鎬、錘子、鋸子、刀、繩子、水桶、燈籠、火把、地圖、鐵砧…，**沒有魚竿**；其他 14 包用 `fish／rod／pole／hook` 搜也都沒有。最接近的是 `spear_A`（長矛）、`staff_A／B`（法杖）、`rope_bundle`（繩圈）。**所有包裡也沒有魚的模型**。→ 魚竿和魚要自己用程式拼（一根細圓柱＋線＋小球浮標；魚＝壓扁的橢圓球），或去別家找 CC0。
2. **人物：免費包裡只有 4 個骷髏（Skeleton Mage／Minion／Rogue／Warrior）**，跟我們已經用的 Adventurers 五個角色同一副骨架、動畫通用。其他人物（Mystery Monthly 系列 14～15 個一包）要付費（$19.99）；我沒有下載。
3. **樹**：Forest Nature Pack 有（見第 2 節）。

## 2. 針對現在做的第 1 關，建議可以換成這些
| 現在 | 可以換成 | 來源 | 備註 |
|---|---|---|---|
| 主角手上的鏟子（程式拼的方塊） | `shovel` | RPG Tools Bits | 掛在右手骨頭上，跟斧頭一樣做法 |
| 冰洞釣魚的魚竿 | **沒有現成**；程式拼細竿＋線＋浮標 | — | 可用 `rope_bundle` 當線的裝飾 |
| 生魚、烤魚 | **沒有魚**；程式拼橢圓球魚；烤好的可以用 `ham_cooked`／`steak` 當「肉」風格 | Restaurant Bits | 如果想要真的烤魚，只能自己拼 |
| 冰窖旁的木桶、木箱 | `barrel_large`、`box_large`、`crates_stacked`、`chest` | Dungeon Pack | 作者之前說倉庫雜物沒作用就拿掉，這次要有用途才加（例如冰窖裡存量的外觀） |
| 錢的圖示、流民付的錢 | `coin`、`coin_stack_*` | Dungeon Pack／Board Game Bits | 飄字旁邊的小硬幣 |
| 冰湖水面 | `hex_water`、`waterlily` | Medieval Hexagon | 現在是程式畫的圓；可換 |
| 森林的樹 | `Tree_Bare_*`（光禿）、`Tree_2_*` | Forest Nature Pack | 風格跟房屋一致 |
| 雪地裝飾 | `snowman_A／B`、`snowball_pile` | Holiday Bits | 圍欄外幾個點綴 |
| 圍欄的門 | `fence_gate` | Halloween Bits | 現在的門只是留空缺 |
| 火堆 | `woodstove`（柴火爐）或自己的石圈 | Mixed Bag 1 | 看你要哪個感覺 |
| 夥伴人物 | 骷髏 ×4（敵人用） | Skeletons | 免費人物很少 |

## 5. 要注意
- 這些我**只看過清單和圖鑑，還沒放進遊戲**。要用哪個，你說，我再挑檔複製進 `assets/models/kaykit/`，更新「關於／素材來源」畫面和 `docs/素材來源.md`。
- 每個包貼圖不同（各自一張漸層貼圖），所以同時用很多包會多載幾張貼圖；手機效能要留意（一次不要用太多包）。
