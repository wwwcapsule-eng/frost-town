## 2. 資源線（只有三條線＋人口＋錢，每樣都有人用）
| 資源 | 從哪來（親手 → 雇人 → 機器） | 誰在用 | 不夠會怎樣 |

| 🪵 木板 | 親手砍山腳樹 → 雇伐木工 → 🛷 雪橇送進倉庫 | 蓋加工廠、塔、石爐木架、修牆 | 蓋不了新建築 |
| 🪨 石材 | 親手敲岩壁 → 雇採石工 → 採石場升級 | 蓋石屋、升級倉庫／石爐／塔 | 住不下人、升不了級 |
| ⚫ 煤 | 親手挖 → 雇礦工 → 🛤️ 木軌礦車自動出煤 | 石爐燃料（比木頭耐燒 4 倍）、升級石爐 | 暖氣縮小、建築停工 |

- 倉庫自動：煤低於 70% 補石爐；木板、石材自動給付款格用（跟第 2 關一樣）。

## 7. 自給自足 → 雪崩 → 遷徙
1. **預告 20 秒**：山上傳來轟隆聲、警示列倒數「🏔️ 雪崩 N 秒後來襲」、北邊山壁先掉小雪塊；提醒「物資放進倉庫（有石牆保護）」。
2. **雪崩 3 波（每波 12 秒）**：北邊山壁滾下雪，地上出現**紅圈**（落雪區，從北往南逼近），圈內的人被擊退並掉一半揹包、建築受傷；紅圈只掃**北半邊**（採石場、煤礦、塔北）→ 玩家要把人和東西撤到南邊；工人自動躲進石屋。
3. **熊王**在第 2 波同時從東側出現，要用塔和主角擋。
4. 3 波撐過（石爐沒滅、居民沒死光）→ 採石場和煤礦被雪埋住（模型換成雪堆）→ **劇情卡**「山腳的雪埋了礦坑……南邊河谷有黏土」→ **過場動畫**（建築沉進雪裡、全村往南走）→ 下一關。
5. 失敗規則：石爐熄了或居民死光 → 雪崩暫停，30 秒後重來（跟第 1 關暴風雪同一套）。
6. 帶去下一關：全部的錢、居民折半（最多 5 人）、倉庫的 2 成材料。
