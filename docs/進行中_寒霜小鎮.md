## 技術備忘
- 全部在 `index.html`；數值集中在 `CFG`；存檔 key `frost-town-save-v1`（`save` 物件，新欄位要給預設值）
- 站點（鋸木廠／烤肉攤）用 `makeMill(x, z, { name, accept, value, time, customers })`
- 背上物品是 `carried` 陣列，每個 mesh 的 `userData.type` 是 `'log'` 或 `'meat'`
- 測試：`window.__game`（step、render、save、bears…）；內建瀏覽器的分頁在背景時 requestAnimationFrame 會變慢，用 `g.step(1/30)` 手動推進再 `g.render()` 截圖
- 本機伺服器：`.claude/launch.json` 的 `frost-town`（node tools/serve.js，port 8080）
