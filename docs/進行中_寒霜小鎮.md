## 容易踩的坑
- 作者要「做完、自己測完才說完成」，不要拿半成品讓他邊玩邊改
- 格子／標籤／建築不可互相遮擋；格子以建築為基準對稱擺放；地方不夠就擴地
- PR 合併後不要再往同一分支推新版，要從 main 開新分支
- 換關一律走 `migrateTo(n, change)`，不要自己改 `save.stage` 再 reload（會漏存地圖進度）
- `stage3Test` 不會自動載入：console 先 `document.body.appendChild(Object.assign(document.createElement('script'),{src:'tools/stage3-test.js'}))`
- 測試用內建瀏覽器的預覽伺服器常要重新 `preview_start`；內建瀏覽器會快取舊 js，改完要重開分頁
- 用量很吃緊（這個對話一輪就從 76% 到 95%）：大檔不要整個讀，用 grep 找段落
