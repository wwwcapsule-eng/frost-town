## 容易踩的坑
- 作者要「做完、自己測完才說完成」；第 4 關的數值是估的，手機實玩再調
- 格子／標籤／建築不可互相遮擋；PR 合併後不要再往同一分支推新版
- 換關一律走 `migrateTo(n, change)`；`story()` 的 go 按鈕按下後會先解除暫停再呼叫 fn
- 程式檔是 CRLF 換行：腳本整段取代要處理 `
`；Bash heredoc 裡寫 `\n` 會被吃掉，改用 String.fromCharCode(92)
- `stage3Test`／`stage4Test` 不會自動載入：console 先把 `tools/stageN-test.js` 用 script 標籤載入
- 內建瀏覽器會快取舊 js：網址加 `&v=數字`；預覽伺服器常要重新 `preview_start`
- 用量／context 吃緊：stage*.js 很大（75KB），用 grep 找段落，不要整個讀
